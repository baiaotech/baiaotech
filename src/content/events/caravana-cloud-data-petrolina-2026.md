A Caravana Cloud and Data — edição Petrolina acontece em 17 de outubro de 2026, na UNINASSAU - Petrolina. O encontro presencial reúne profissionais de tecnologia para compartilhar conteúdo sobre computação em nuvem e plataformas de dados.

A programação anunciada inclui sessões sobre migração do SQL Server para Azure, AWS, OCI ou Google Cloud, uso de SQL Server e Power BI e fundamentos de Azure. A inscrição é gratuita, com entrega de 2 kg de alimentos no credenciamento.
